# 📚 OpenCV 学习指南

欢迎来到 OpenCV 交互式学习教程！本指南将帮助您从基础开始学习 OpenCV 的使用及原理。

## 📋 目录结构

- `opencv_tutorial.py`: 交互式学习教程，包含6个循序渐进的章节
- `requirements.txt`: 所需依赖包列表
- `sample_image.py`: 用于生成示例图像的脚本
- `README.md`: 项目说明文档

## 🚀 开始学习

### 1. 安装依赖

首先，安装所需的Python包：

```bash
pip install -r requirements.txt
```

### 2. 生成示例图像

运行以下命令生成用于练习的示例图像：

```bash
python sample_image.py
```

这将创建一个名为 `sample_image.jpg` 的图像文件，包含基本形状和文本。

### 3. 运行交互式教程

启动交互式学习教程：

```bash
python opencv_tutorial.py
```

按照教程中的指示，按回车键逐步学习各个章节的内容。

## 📖 教程内容概览

教程包含以下6个章节：

1. **OpenCV 简介** - 了解OpenCV的基本概念、特点和应用领域
2. **安装 OpenCV** - 学习如何正确安装OpenCV及其依赖
3. **OpenCV 基础操作** - 掌握图像的读取、显示和保存等基本操作
4. **基本图像处理** - 学习颜色空间转换、图像裁剪、缩放和旋转等操作
5. **OpenCV 高级主题** - 探索边缘检测、轮廓检测、直方图计算和视频处理
6. **实践练习** - 通过练习题巩固所学知识

## 💡 学习建议

1. **循序渐进** - 按照教程的顺序逐步学习，确保理解每个概念
2. **动手实践** - 不要只阅读代码，亲自编写和运行示例
3. **尝试修改** - 对示例代码进行修改，观察结果变化
4. **解决问题** - 完成教程末尾的练习题
5. **查阅文档** - 遇到问题时，参考OpenCV官方文档

## 🔧 常见问题

### 安装问题

如果在安装过程中遇到问题，可以尝试以下解决方案：

- 确保已正确安装所有依赖包
